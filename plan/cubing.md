# Cubing implementation

## Scope

Independent 3×3 timer and OLL/PLL training with Fbin-inspired visual style, local browser storage, JSON backup, sessions and statistics, keyboard and touch controls, inspection and penalties, and offline availability after resources have been cached. Showcase integration must be a link to a deployed URL only; no shared code, dependencies, configuration, secrets, or data. No backend or cloud sync.

User-approved 2026-11-10 extension: essential csTimer-like 3×3 functionality includes manual time entry, editing results, mo3, progress visualization and F2L/Cross training after generator correctness is verified. Continue OLL/PLL case selection and statistics; don't claim unverified generators as complete. Exclude other puzzle types, cloud/accounts, donation panels, ZBLL and other methods, Stackmat, smart cube, reconstruction, multi-phase and metronome for this scope. English UI. Direct browser inspection of csTimer was specifically authorized; use GPT for other external research. Preserve browser data and existing repository work. Remote creation, publishing and deployment remain separately gated.

## Phases and acceptance

1. Set up standalone repository and toolchain; validate a clean install and build.
2. Implement and test timer, local persistence, import/export and statistics.
3. Implement 3×3 scrambles and correct selectable OLL/PLL case training after verifying generator and license. Never label ordinary scrambles as training scrambles.
4. Implement responsive UI, keyboard/touch accessibility and offline support; test desktop/mobile and themes.
5. Link the independently deployed demo from the showcase only after deployment and URL are confirmed. The user requested MR delivery, a public remote, and a separate Vercel deployment; merging remains separately gated.
